# Linux Homework

Linux is a family of open-source Unix-like operating systems based on the Linux kernel, which was first released on September 17, 1991, by Linus Torvalds.

## Key Concepts

- **Kernel**: The core of the operating system that manages hardware and system resources
- **Shell**: Command-line interpreter that allows users to interact with the kernel
- **Filesystem**: Hierarchical file organization starting from the root directory `/`
- **Processes**: Running instances of programs managed by the kernel

## Common Commands

- `ls` - List directory contents
- `cd` - Change directory
- `pwd` - Print working directory
- `mkdir` - Make directories
- `rm` - Remove files or directories
- `cp` - Copy files and directories
- `mv` - Move or rename files or directories

## File Permissions

Linux uses a permission system for files and directories:
- **Read (r)**: 4 - Can read the file contents
- **Write (w)**: 2 - Can modify the file
- **Execute (x)**: 1 - Can execute the file as a program
- **Owner/Group/Others**: Permission levels

Permissions are often represented in octal notation (e.g., 755, 644).
